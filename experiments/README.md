# experiments/ — the relentless loop

One directory per experiment that is **next up**: a full executable BRIEF.md a
worker can run cold. The registry of all rungs and their statuses stays in
`../PROGRAM.md` §3 — this directory never duplicates it, and a brief is
deleted once its rung is EXECUTED (the pack becomes the record).

The loop, every time:

1. **Brief** here — falsifiable readouts, denominators, spend cap, corpus.
2. **Harness** in llmsorting `examples/` (that's where the engine seams are;
   research instruments never get public verbs — llmsorting AGENTS.md law).
3. **Pack** in llmsorting `artifacts/live/<slug>-<date>/` — report.json,
   trace.jsonl, RESULTS.md with denominators, errata-on-top.
4. **Flip the rung** on llmsorting.com + PROGRAM.md to EXECUTED with the
   measured numbers, deploy, delete the brief.

Offline synthetic validation before any live call; live runs under an
explicit dollar cap on existing credit; a malformed answer is a recorded
failure, never a default.
